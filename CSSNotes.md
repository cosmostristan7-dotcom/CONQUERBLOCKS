# CSS Color Reference Sheet

## 1. Basic Common Colors
* **Black:** `black` or `#000000`
* **White:** `white` or `#ffffff`
* **Red:** `red` or `#ff0000`
* **Blue:** `blue` or `#0000ff`
* **Yellow:** `yellow` or `#ffff00`
* **Green** `green` or `#008000`
* **Hex Code**, pine green color = `#1b4d3e`

## 2. Professional Premium Colors
* **Navy Blue:** `navy` or `#000080` (Great for corporate or legal layouts)
* **Gold:** `gold` or `#ffd700` (Excellent for accents or borders)
* **Dark Green:** `#1b4d3e` (Favorite workspace/aesthetic green)
* **Charcoal Grey:** `#2f3640` (Excellent for dark mode backgrounds)
* **Soft White/Off-White:** `#f5f6fa` (Great for light mode backgrounds)

## 3. Quick CSS Syntax Reminder
```html
<!-- Inline HTML example -->
<h1 style="color: navy; text-align: center;">Title</h1>

<!-- Inline CSS custom Hex example -->
<p style="color: #1b4d3e;">Text color here</p>


<h1 style="color: white; text-align:center;">PRUEBA</h1>

<tr>
    <td style="text-align:right; width:70%; vertical-align:middle;">POMMES
    </td>
</tr>

<h1 style="color: green; text-align: center;">The Power of <span> for Inline Accents</h1>

<p>Right now, you are applying styles to block elements like <h1 style="..."> and <p style="...">, which change the color of the whole line. If you ever want to highlight just a single word or phrase inside a sentence, use a <span> tag:</p>

<p>This is a regular sentence, but <span style="color: #1b4d3e; font-weight: bold;">this specific part</span> is premium dark green.</p> 
```
