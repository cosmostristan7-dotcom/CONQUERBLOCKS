REGISTRY OF ENTITIES

Entities are the building blocks of a web page. They can be

text, images, links, or other elements

that make up the content of a webpage.

In HTML, entities are used to represent characters that have special meanings in the language, such as the ampersand (&) or the less-than sign (<). These characters can be represented using their entity names or numeric character references. They start by typing <a href="https://example.com"> Link Text</a>

To insert a website link, you can use the <a> tag with the 'href' attribute to specify the URL of the page you want to link to.

Example:

Visit my CND Studio.

This will create a clickable link that will take you to this domain: "https://cndstore.onrender.com" when clicked.

To insert an image, you can use the <img> tag with the 'src' attribute to specify the path to the image file and the 'alt' attribute to provide alternative text for the image.

This task is about the use of the <img> tag in HTML. The <img> tag is used to embed images in a web page. It requires the 'src' attribute to specify the path to the image file and the 'alt' attribute to provide alternative text for the image.

Example:

The 'src' attribute can point to an image file located on the same server or an external URL. The 'alt' attribute is important for accessibility, as it provides a text description of the image for screen readers and when the image cannot be displayed.

For more information on the <img> tag, you can visit, MDN Web Docs.
