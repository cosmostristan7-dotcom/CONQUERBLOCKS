SEMANTIC TAGS

With or without them our HTML information can look just equal. However, if we use them, our HTML code will be more specific and detailed. They always have to be included within the <body></body> tags.

They can be:

1. GROUPING TAGS.
2. BLOCK-LEVEL GROUPING TAGS.
3. CONTAINER TAGS.
4. STRUCTURAL GROUPING TAGS.

1. GROUPING TAGS

Grouping tags are HTML elements whose main purpose is to organize content. They don’t necessarily describe meaning; they simply help you group related items together so your page is easier to structure and style.

Examples:
• <div> — generic grouping
• <span> — inline grouping
• <p> — paragraph grouping
• <ul> / <ol> — list grouping
• <li> — list item grouping

Use grouping tags whenever you need to collect elements into a single unit.

2. BLOCK-LEVEL GROUPING TAGS (<div> - <section> - <article> - and so on)

Block‑level grouping tags create large structural blocks in your layout. They always start on a new line and expand to the full width available.

<div>

A generic block container with no semantic meaning. Use it for layout, wrappers, and when no other tag fits.



<section>

A thematic block of content. Use it when your content has a topic, heading, or theme.



<article>

A self‑contained block that can stand alone outside the page. Use it for blog posts, news, product descriptions, etc.



<nav>

A block containing major navigation links.



<header> / <footer>

Introductory and closing blocks for a page or section.



Block‑level grouping tags help you build the structure of your webpage.

<span>

Stands for a generic inline container used in HTML to group text or elements for styling or scripting purposes.

Display Behavior: <span> is an inline element, meaning it flows naturally within a line of text without forcing line breaks. Both <section> and <article> are block-level elements that break to a new line and take up the full available width of their container.

3. CONTAINER TAGS

Container tags are elements whose main job is to hold other elements inside them. They may be semantic or non‑semantic.

Examples:
• <div> — generic container
• <section> — thematic container
• <article> — content container
• <form> — container for inputs
• <table> — container for tabular data
A container tag is used when you need a box to place multiple elements inside and treat them as one unit.

Examples per each tag:

4. STRUCTURAL GROUPING TAGS

Structural grouping tags define the architecture of your webpage. They give meaning to the layout so browsers, search engines, and screen readers understand the structure.

Examples:
• <header> — top section
• <footer> — bottom section
• <nav> — navigation
• <main> — main content
• <aside> — complementary content
• <section> — thematic block
• <article> — independent content
These tags make your HTML semantic, accessible, and easier to maintain.

<main>...</main> TAG.

The <main> tag specifies the dominant, central content of a document's body, directly related to the central topic or application functionality. It acts as a structural landmark for screen readers and search engines, ensuring that repetitive elements like navigation menus, headers, footers, and sidebars are excluded from the primary narrative. Only one unique <main> element should exist per page, and it cannot be a descendant of an <article>, <aside>, <footer>, <header>, or <nav> element.

Example:

    </header>

    <main>
        <h1>Welcome to My Website</h1>
        <p>This is the unique, central content of the webpage.</p>
    </main>

    <footer>
        <p>&copy; 2026 Example Corp</p>
    </footer>

FORMS:

An HTML form (<form>) is a container used to collect user input—such as text, selections, or files—and send it to a server for processing or handle it via JavaScript.

Core Concept:

Purpose: Collects interactive user data (e.g., logins, searches, registrations, contact details).

Key Attributes:
action:
Specifies where the collected data is sent upon submission.
method:
Defines how data is sent (commonly GET for retrieving/querying data or POST for secure submissions).
KEY ELEMENTS:

Uses controls like <input>, <textarea>, <select>, and <button> wrapped inside <label> tags for accessibility.

FORM'S ATTRIBUTES

action
Backend URL address to where the form information will be sent.
method
HTTP sending method. GET by URL. POST for bigger sending data.
name
Form name. Useful to identify the form and process it eventually.
target
Name of the site where the form will be opened. (_blank) to start a new window.
enctype
Sending form encryption. Important for file sending.
accept-charset
Forces an encryption when form text settings are used.
autocomplete
Turns autofilling ON/OFF for the form.
novalidate
(BOOLEAN) Deactivates HTML5 validation on a form.
