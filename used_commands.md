## FILE MANAGEMENT:

- `whoami = [type command, press enter]`, "It shows the user_name".
- `who = [type command, hit enter]`, "it shows who is connected".

* `pwd = [type command]`, "It displays the current user's path".
* `mkdir = [folder_name]`, "It makes new DIRECTORIES or FOLDERS".
* `mkdir -p = [new_folder_name]`, "It makes parent directories".

* `nano + file.name.txt`, "creates basic text files (ficheros de txt).

* `touch + file_name.md`, "creates better text files". (file.md)
  '''When creating a file.md, open it from the terminal by typing code, file_name.md // then press enter.'''

* `touch = [file_name.txt]`, "creates simple text files". (file.txt)
  '''When creating a file.txt, open it from the terminal by typing open, file_name.txt // then press enter.'''

  "Si lo que has creado en la terminal es un file.html or file.css, para abrirlos, escribe code + file.html or file.css, press enter."

* `ls = [path/folder_name, ls]`, "It lists items within folders".

- `ls -l = [type command]`, "It lists items and code description".

* `cd = [cd, folder_name or file_name]`, "navegates around".
* `mv = [mv, folder_name new_name]`, "renames a file".
* `mv = [mv, file_name folder_name]`, "moves files to a new folder".
* `mv = [mv, file_name]`, "creates a new file_name out of no-where".

## REMOVING OR DELETING FOLDERS AND/OR FILES:

- `rm = [rm, file_name]`, "removes specific files or documents".
- `rm -r = [rm -r, folder_name]`, "deletes folder itslef n content2".
- `rmdir = [rmdir, folder_name]`, "removes empty folders".

  '''IMPORTANT: the terminal doesn't have a recycle bin, therefore, any documents, files, folders or photos deleted or removed will be forever gone.'''

## COPYING FILES.TXT/FILES.MD:

- `cp = [cp origin.txt odd.txt], [cp origin.md copy.md]`,
  "It copies the info. from file.txt/.md to another one under the same type. It keeps the same permission, who can read and write."

- `cat = [cat origin.txt], [cat origin.md]`,
  "It reads the text and displays it on the terminal".
